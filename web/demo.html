How the stream works

One Range request per block, overlapped with compute.

  1. 01
    Range fetch
    Request bytes=start-end for one safetensors block.
  2. 02
    Prefetch
    The next block downloads while the current block computes.
  3. 03
    Real compute
    BF16 RMSNorm → grouped-query attention → SwiGLU MLP on the streamed bytes.
  4. 04
    Evict
    The buffer releases the block, keeping the working set bounded.
Honest scope. This view streams the 22 Transformer blocks and starts from a random hidden state; no token embedding is applied, so the checksum is a pipeline sanity signal, not model output. Baseline numbers are produced separately by examples/end_to_end.py, not by this page.
