System Architecture

End-to-end cloud-native architecture of the Asynchronous Progressive Layer-Streaming Engine.

1. Client Invocation Layer

Dispatches HTTP inference requests and configuration payloads to cold-started serverless worker containers.

2. Serverless Function Container

Dockerized Python/PyTorch worker with strict memory/CPU cgroups (2 GB RAM cap) and zero local model cache.

3. Tokenizer & Embeddings

Maps prompt tokens to initial hidden states [1, L, d_model] using the lightweight embedding table before decoder blocks.

4. Progressive Inference Engine

Orchestrates layer-by-layer forward passes without blocking on full checkpoint ingestion.

5. Asynchronous Prefetcher

Producer coroutine bounded by asyncio.Semaphore(K) issuing RFC 7233 HTTP Byte-Range GETs ahead of compute.

6. Bounded Ring Buffer

Holds at most K+1 layer payloads in RAM and immediately evicts completed layers to prevent serverless OOM.

7. PyTorch Transformer Engine

Zero-copy torch.frombuffer deserialization executing RMSNorm, RoPE, Causal GQA, and SwiGLU MLP blocks.

8. Cloud Object Storage (S3 / MinIO)

Hosts disaggregated SafeTensors checkpoints accessible via byte-range HTTP GETs over MinIO or RangeServer.

Analytical Performance Model

Monolithic loading serializes full-checkpoint transfer and forward-pass execution:

T_mono = T_boot + Σ(Size(W_i) / B_net) + Σ T_compute(i)

Progressive streaming overlaps layer i+1 transfer with layer i computation:

T_prog = T_boot + (W_0 / B_net) + Σ max(W_{i+1}/B_net, C_i) + C_{L-1}
Masking M = clamp(1 - T_io_wait / T_net_total, 0, 1)
Peak ΔRSS = O((K + 1) · Size(W_layer))
